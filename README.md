# CNN Flower Picture Classification

This project uses a Convolutional Neural Network (CNN) to classify flower images.

## Project Goal

The goal of this project is to build a deep learning model that can recognize different types of flowers from images.

## Technologies

- Python
- TensorFlow
- Keras
- NumPy
- Matplotlib

## How It Works

1. Flower images are given to the model.
2. The images are processed and prepared for the model.
3. A CNN model learns patterns from the images.
4. The trained model predicts the type of flower in a new image.

## Project File

The main project file is:

`flowes.ipynb`

## Result

The trained CNN model can be used to predict the class of a flower image.
